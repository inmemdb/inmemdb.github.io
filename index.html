inMemDB

Embedded in-memory database for Go.

inMemDB runs inside your Go executable, giving services, CLIs, tests, and local-first tools fast structured storage without a separate database server.

View on GitHub See the Go shape
embedded.go pure Go 
package main

import (
    "context"

    "github.com/inmemdb/inmemdb-go"
)

func main() {
    ctx := context.Background()

    db, err := inmemdb.Open(ctx)
    if err != nil {
        panic(err)
    }
    defer db.Close()

    // Use through the Dalgo database API.
    _ = db
}

Why inMemDB

Use inMemDB when your application needs temporary, fast, embedded data storage with a real database-shaped API.

No server process

Ship storage inside your Go binary and keep deployments simple.

Good for tests and tools

Back CLIs, local workflows, fixtures, and ephemeral app state.

Open source first

Developed in public as part of the Dalgo database ecosystem.

Made to embed into Go executables

inMemDB is implemented in Go and designed to be linked directly into Go applications. It is a library you import, not another service to run.

  • In-process storage for services and command-line tools
  • Simple setup for integration tests and development fixtures
  • API exposed through a Dalgo adapter

Powered by Dalgo

The project exists to make the Dalgo adapter model easier to try, embed, and understand. If you can use inMemDB, you can see how Dalgo database implementations fit together.
