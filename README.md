# inMemDB website

Static website for the `inmemdb.github.io` GitHub Pages site.

The site intentionally has no build step. Edit `index.html` and `styles.css`,
then push to the default branch of `github.com/inmemdb/inmemdb.github.io`.

The inMemDB Go implementation is expected to live at
`github.com/inmemdb/inmemdb-go` and use Apache-2.0 unless the project chooses
to match a different upstream Dalgo license.
